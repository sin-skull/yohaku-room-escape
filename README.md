# 余白 — YOHAKU

Three.jsで作った、和室と廊下と書院を巡る脱出ゲームです。

現在の公開版：**v1.5.0** / [遊ぶ](https://sin-skull.github.io/yohaku-room-escape/) / [拡大できる制作図](https://sin-skull.github.io/yohaku-room-escape/project.html)

v1.5.0では、スライドで見回し、行ける場所だけ画面下の矢印から移動する操作を三か所に先行実装しました。[再設計R2](docs/REDESIGN-R2.md)の五問はまだ設計段階です。[ロードマップ](docs/ROADMAP.md)で実装済みと未実装を区別しています。

[制作の指針・ES図・ロードマップ](docs/README.md) / [30段階の分岐設計案（未実装）](docs/PUZZLE-30.md) / [変更履歴](CHANGELOG.md)

部屋はピンチ・ホイール・＋−で拡大縮小できます。「正面」で正面へ、「戻」で初期位置・視点へ戻ります。掛け軸の図もタップ・ピンチで拡大でき、数字錠はタップ・上下・スワイプで循環します。ヒントは専用ボタンから開けます。

画面をスライドすると360度見回せます。向いている方向に移動先があるときだけ、画面下に矢印が出ます。矢印をタップすると、その場所や隣の区画へ移動します。足跡アイコンで歩行／神目線を切り替えます。物をタップすると近づいて調べます。壁と家具はすり抜けません。

上部の〈 〉から持ちものを開閉。一度タップで選択、同じ物を再タップで解除。選んだまま対象に触れると使います。目の印でアイテムを詳しく見られます。所持しているだけでは自動使用しません。

- スライドで3Dの部屋を見回し、クリック・タップで調査できます。
- 書院の俯瞰と廊下の覗き棚で別々の手がかりを発見し、静寂の間へ持ち帰って格子の仕掛けを開きます。
- 発見した手がかりだけが覚え書きに残ります。箪笥を開け、鍵を選んで襖に使うと脱出できます。
- 画面下の移動矢印や襖のタップで区画を移動。間取で現在地を確認でき、現在地と進行を保存します。
- 制限時間はありません。公開版は三か所を巡る最初の区画で、館全体と30段階の謎は制作計画です。[区画の詳細](docs/WING.md)
- 進行状況はブラウザに自動保存されます。
- 設定で画像中心の表現と従来の立体細部を切り替え、描画負荷を比較できます。

## ローカルで起動

Node.jsをインストールした環境で `npm start` を実行し、表示されたURLを開いてください。ビルドや追加パッケージのインストールは不要です。

## 素材と軽量化

家具の輪郭・奥行き・可動部分・鍵は3D形状です。木目、壁、畳の縁、障子の細い桟、箪笥の装飾は小さな画像で表現します。7素材を約16KBの共有WebP画像にまとめています。

素材の生成元は `tools/build-textures.py`（Python / Pillow）、描画負荷の試験記録は `tools/texture-pilot-results.json` です。実機FPSの保証値ではありません。

Three.jsのライセンスは `vendor/LICENSE.three.txt` を参照してください。本文表示はシステムの明朝体を使います。環境音は操作に応じてブラウザ内で生成します。
