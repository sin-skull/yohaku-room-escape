# 操作仕様 — v1.5.0

現在の三か所で、スライドを見回し、画面下の矢印を移動に分けた。再設計R2の五問、近接から一つ前へ戻る操作、アイテム詳細の拡張は未実装。[ロードマップ](ROADMAP.md)を参照。

| 操作 | 動作 |
|---|---|
| 3D画面をスライド・ドラッグ | 歩行視点では360度見回す。上下で視線の高さを変える。押し続けても歩かない |
| 画面下の矢印をタップ | 表示された場所へ移動。家具を避けて歩き、出入口なら隣の区画へ進む |
| 移動矢印の表示 | 向いている方向にあり、到達可能な場所だけ。到着済みの室内地点は隠す。正面に移動先がなければ矢印を出さない |
| 足跡／俯瞰アイコン | 歩行視点と神目線の切り替え。神目線でもスライドで部屋を回せる。神目線の移動矢印は隣の区画への移動だけ |
| 物をタップ | 家具を避けて近づき、調べる。神目線では画面を寄せる |
| 襖の目印をタップ | 隣の区画へ進む。アイテム選択中でも移動できる |
| 間取 | 現在地と訪問済みの場所を和紙の図で見る |
| 二本指・ホイール・＋− | 拡大縮小する |
| 正面 | 今の位置から部屋の正面へ向く |
| 戻 | 初期位置と視点に戻す。一つ前の視点へ戻る機能は今後追加 |
| 上部の〈 〉 | 持ちものを開閉。選択中の小さな図は残す |
| アイテムを一度タップ | 選択する。同じ物を再タップで解除、別の物なら選択を変更 |
| 選択した状態で対象をタップ | アイテムを使う。所持だけでは自動使用しない |
| 目の印 | 選択中のアイテムを拡大。現行版では再タップは解除、ダブルタップ拡大は未実装 |
| 神目線の「俯」 | 注視している物を上から見る |
| 「写す」 | 現行の視点謎で、見え方が合った手がかりを覚え書きへ残す |
| ヒント | 専用ボタンから段階的に見る |

移動矢印には行き先の短い名前を添える。モーダル表示・移動演出中は矢印を隠す。ドラッグ終了を調査タップとして扱わず、二本指操作後も誤タップを防ぐ。移動中のスライド、メニュー、中断、別タブへの切り替えは移動を止める。

壁・家具の簡単な当たり判定と操作時だけの経路探索を使う。物理演算は使わない。静止中は連続描画を止め、DPR上限1.5と共有画像を維持する。

保存済みの謎・訪問地・所持品は引き継ぐ。旧操作設定からの初回更新では視点だけを室内へ戻し、その後は選んだ視点を保存する。キーボードでは左右キーで90度回転、WASD／上下キーでも従来の移動ができる。

## 確認範囲

経路・方向・到着・非表示を含む自動テスト29件が成功。デスクトップブラウザと390×844の表示で、スライド前後の立ち位置不変、矢印からの室内移動、三か所の往復、神目線、既存の調査画面を確認。スマホ幅での表示確認は、実機タッチ試験とは別。iOS Safari / Android Chromeでの実機評価と、人による初見試遊は未実施。
