# 操作仕様 — v1.3.0

ユーザーの指定を反映し、足跡アイコンは「歩行／神目線」の切り替えとする。アイコンを長押しして歩く方式ではない。

| 操作 | 動作 |
|---|---|
| 足跡アイコンをタップ | 歩行視点と神目線を切り替える。歩行中は印の色が変わる |
| 歩行中、画面上の任意の探索位置から上へスワイプ | 指を押さえている間、前進する |
| 同じ操作を下へ | 後退する |
| 同じ操作を左右へ | 向きを変える。斜めなら移動しながら曲がる |
| 指を離す・操作が中断される | 移動を停止する。画面外・別タブへの切り替えでも停止する |
| 神目線でスワイプ | 部屋の外から360度回す。手前の壁と天井は隠し、奥を見せる |
| 物をタップ | 歩行中は家具を避けて近づく。神目線ではその物へ画面を寄せる |
| 二本指・ホイール・＋− | 拡大縮小する。歩行位置を壁の外へ押し出さない |
| 上部の〈 〉をタップ | 持ちもの欄を開閉する |
| アイテムを一度タップ | 選択する。印が付き、欄を閉じても選択中の小さな図を残す |
| 同じアイテムを再びタップ | 選択解除する。別のアイテムを選ぶと選択を切り替える |
| アイテムを選んで部屋の対象をタップ | 対象に使う。所持しているだけでは自動使用しない |
| 選択中に目の印をタップ | アイテムの図を詳しく見る。選択操作と詳細表示を分ける |
| 神目線の「俯」 | 注視している物を上から見る。高い飾り棚では墨の断片が揃う |
| 「写す」 | 視点が合い、手がかりが見えているときだけ現れる。発見を覚え書きへ残す |
| ヒント | 専用のヒントボタンから段階的に見る |

探索位置とは3D画面と調査の目印。メニュー、アイテム欄、錠の操作から歩行を発火させない。指を二本にした後も、指を離した動作をタップとして扱わない。

机・箪笥・行灯・床の間・壁には、軽い平面上の当たり判定を置く。物理演算は使わない。タップ接近の経路は操作時だけ求め、止まっている間は毎フレーム描画しない。神目線の壁非表示は表示上の処理で、歩行時の壁や当たり判定は残す。

鍵を手に取る → 〈 〉 → 鍵を一度タップ → 襖をタップ → 襖が開く、を現行の一部屋で確認する。館と30段階の追加謎はこの版では未実装。

## 確認と残る試験

数字・ポインター・歩行経路・当たり判定・アイテム選択と使用の自動テスト、デスクトップブラウザの通しプレイを行う。スマホ幅での確認と実機タッチ試験は別であり、iOS Safari / Android Chromeの実機評価は引き続き必要。
