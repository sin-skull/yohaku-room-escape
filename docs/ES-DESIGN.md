# ES図 — 行動・発見・感情

この計画の「ES図」は、プレイヤーの行動・発見・感情を重ねる体験設計図として暫定的に扱う。業界共通の用語と断定しない。感情は設計意図であり、実測結果ではない。

```mermaid
flowchart LR
  enter["和室に入る・落ち着く"] --> look["見回す・気になる物を探す"]
  look --> focus["触れて寄る・もっと見たい"]
  focus --> ink["墨絵の数に気づく・発見"]
  ink --> match["錠の草木と対応づける・仮説"]
  match --> turn["数字を上下に回す・試す"]
  turn -->|"違う組み合わせ"| retry["動かない・観察し直す"]
  retry --> ink
  turn -->|"対応が合う"| drawer["引き出しが開く・納得"]
  drawer --> key["鍵を手に取る・前進"]
  key --> door["襖が開く・解放"]
  door --> after["余韻・誰かに話したい"]
  look -.-> hint["自分でヒントを開く"]
  retry -.-> hint
  hint -.-> ink
```

| 場面 | 美術の必要性 | 観察で確かめること |
|---|---|---|
| 全景 | 畳・障子・床の間で向きと注目箇所をつくる | 説明なしで最初の調査へ進めるか |
| 掛け軸 | 松竹梅の墨絵が数の手がかりを担う | 草木の種類と数を読み取れるか |
| 箪笥 | 木の錠、刻印、引き手で操作を示す | 上下・タップ・引く操作が分かるか |
| 正解 | 引き出しと音の変化が因果を返す | 正解した理由と結果が伝わるか |
| 不反応 | 和紙の短い墨書きで応答する | 操作失敗と無反応な物を区別できるか |
| 脱出 | 襖の開閉と光で終わりを示す | 達成と余韻を感じるか |

## 実装上の状態

```mermaid
stateDiagram-v2
  [*] --> 探索
  探索 --> 手がかり記録 : 掛け軸を調べる
  手がかり記録 --> 錠操作 : 箪笥を調べる
  探索 --> 錠操作 : 箪笥を先に調べる
  錠操作 --> 錠操作 : 不正解・数字変更
  錠操作 --> 引き出し開 : 正解して引く
  引き出し開 --> 鍵所持 : 手に取る
  鍵所持 --> 鍵選択 : 持ちものの鍵をタップ
  鍵選択 --> 鍵所持 : 同じ鍵を再タップ
  鍵選択 --> 襖開閉中 : 襖をタップして使う
  襖開閉中 --> 脱出 : 開く動きが完了
  脱出 --> 探索 : もう一度
```

ヒントは進行状態を勝手に変更しない。閉じる・拡大・見回す操作でも手がかりや数字を失わない。既存の進行保存を引き継ぐ。

v1.2.0の歩行／神目線・選択操作は[操作仕様](CONTROLS.md)を参照。館版では、各主要部屋の松・竹・梅の最終解を玄関へ集約する。[館の構成](MANSION.md)は現行の一部屋の実装と区別する。
