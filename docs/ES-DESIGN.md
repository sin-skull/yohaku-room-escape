## 必要な物と、演出の出現条件を分ける

```mermaid

  p1["P1 小箱・取手・紙"] --> p2["P2 灯りと廊下・竹の札"]
  p3["P3 模型・松の札"] --> p5["P5 札の裏と館・鍵"]
  p2 --> p5
  p4["P4 閉じる戸・梅の札"] --> p5
  p2 -.-> event["松竹を得て帰還すると知らせ"]
  p3 -.-> event
  event -.-> p4
  p5 --> exit["鍵を選んで玄関へ使う・脱出"]
```

破線は知らせを出す条件であり、梅の札を取るための読了条件ではない。先に戸を閉めても成功。先に模型を解く行動も受け入れる。合理的な先回りを拒否して作者の順序へ戻さない。
