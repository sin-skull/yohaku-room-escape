# 初見プレイテスト

対象は作者の説明を聞いていない10人。普段の脱出ゲーム経験、使用端末・OS・ブラウザを記録する。人を募集・連絡する行為や録画は別途本人の同意を得て行う。現時点では参加者の結果はない。

開始時の説明は「この部屋から出てください。困ったら画面のヒントを使えます。」だけ。観察者は正解を指示しない。操作を発見できないときも、詰まった場所と時間を記録してから補助する。

| 記録欄 | 記入内容 |
|---|---|
| 最初の行動 | 調査までの秒数、どこを触ったか |
| 発見 | 草木・数・錠の対応をいつ自分で気づいたか |
| 操作の障害 | ピンチ、全景復帰、数字変更、引く、鍵取得での迷い |
| フィードバック | 正解、不正解、未操作、仕掛けのない物をどう理解したか |
| ヒント | 開いた段階、役立ったか、答えを明かしすぎたか |
| 終了後 | 「どうして開いたと思いますか」「誰かに話すなら、どの瞬間ですか」「次も遊びたいですか。なぜですか」 |

不具合、操作の迷い、手がかりの読めなさ、推理の飛躍を分けて改善する。絵を増やす前に原因を特定する。改修後は未経験者で再確認する。平均点だけで不満の理由を消さない。


## v1.3.0の視点謎

神目線の墨合わせ、歩行視点の覗き棚、二つの発見から開く格子を一部屋に追加。詳細は[実装と検証](VIEWPOINT-PUZZLES.md)を参照。制限時間は設けない。初見試遊では視点の発見、写す操作、行と列の対応を観察する。
