# 初見試遊R2 — 動いたか、分かったか、楽しんだかを分ける

v1.4.0の作者の通し操作と自動テスト24件は機能確認。新しい五問で人が解法を理解した結果はまだない。

## 順番

1. 謎なしの操作見本で、調べる・戻る・選択・使用・解除を確認する。
2. P1を初見3人で観察する。説明を聞いた後の成功を初見成功と数えない。
3. 修正した五問を別の初見5人で通して観察し、経験と端末を記録する。
4. 同じ人の再試遊は回帰確認とし、新しい初見の評価と混ぜない。

募集・連絡・録画は自動で行わない。本人の同意と実際の参加が必要。ユーザーの指摘を、実施していない試遊人数へ置き換えない。

## 渡す説明

「この館から脱出してください。困ったらヒントを使えます。」と目的だけ伝える。操作は画面内で理解できるようにする。観察者が次の部屋や解法を言う前に、どこで何が分からなくなったかを記録する。

長く困っている人へ続行を強要しない。補助前の状態を残し、本人がヒント・中断を選べるようにする。

## 一問ごとの記録

| 欄 | 記録内容 |
|---|---|
| 状況 | 端末・ブラウザ・謎ID・発見済みと未発見の物 |
| 仮説 | 何をしようとしたか。自然な発話を残す |
| 根拠 | どの形・枠・場所・動きから考えたか |
| 入力 | 押した・なぞった対象。意図した動作になったか |
| 反応 | 成功・不正解・対象外をどう区別したか |
| 停滞 | 操作不明／証拠未発見／関係不明／反応の見落としのどれか |
| ヒント | 使用段階と、その後に本人が考えたこと。答えを教わった完了と区別 |
| 先回り | 先に床板を開けた、戸を閉めた、別の角度で解いた等。合理的なら受け入れる |
| 終了後 | 「なぜそれをしたら開くと思いましたか」「どこで思いつきましたか」 |
| 感情 | 発見した場面、気持ちよかった場面、不満を本人の言葉で残す |

常時考えを話させて没入を壊すことは避け、自然な操作観察と各問後の短い振り返りを併用する。

## 特に見ること

- P1：枠と隅印を比較したか、ランダム入力で開いただけか。
- P2：灯りに紙を使う理由があり、図と実際の柱がつながったか。
- P3：上から見る理由とつなぐ線が分かり、カメラ操作で疲れていないか。
- P4：紙の実在を示す兆候から裏を疑えるか。不具合と思って再読み込み・放置されないか。
- P5：札の裏と館がつながり、作者の植物順を当てようとしていないか。

判定基準は[ロードマップ](ROADMAP.md)へ一本化。人数だけを達成するために答えを目立たせず、証拠と操作を直す。
