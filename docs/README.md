## ディレクション

気づく → 仮説を立てる → 手を動かす → 景色が応える。この循環を、短い一部屋で成立させる。長文で正解へ誘導せず、墨絵・木の錠・引き出しの動きで伝える。補助が必要な人には、常に見つかる「ヒント」から段階的に助ける。

3Dの奥行きと視点操作を残す。家具の輪郭、可動部分、拾う鍵は立体。木目、和紙、汚れ、細かい装飾は共有画像。部屋を写真一枚の平面にはしない。美術の追加は「発見・空間の理解・操作・感情」のどれに役立つかを決めてから行う。

v1.3.0で成立させた視点謎を、v1.4.0では廊下と書院へ分散した。神目線で高さの違う墨を合わせ、歩行視点で棚を覗き、二つの発見を格子の仕掛けへ集約する。発見した情報だけを覚え書きに写し、箪笥・鍵・襖へ進む。制限時間は設けず、秒数制限の評価は制作の最後に回す。人気を生む独自性は、初見の試遊を通じて確かめる。

## 人間の制作者から参照した判断

以下は公開された一次資料。作品の表面を模倣せず、制作上の判断を本作に適用する。適用案は本プロジェクトの仮説であり、各制作者が本作を評価したものではない。

| 参照 | 公開資料で確認できる考え方 | 本作への適用 |
|---|---|---|
| Luis Antonio / Thekla | [GDC 2014「The Art of The Witness」公開概要](https://www.gdcvault.com/play/1021148/The-Art-of-The)：美術チームがゲームの本質を理解し、視覚言語を広げる | 美術を手がかり・誘導・反応へ結びつける。閲覧したのは講演の公開概要 |
| 手塚卓志・毛利志朗ら / 任天堂 | [『スーパーマリオブラザーズ ワンダー』開発者インタビュー第1章](https://www.nintendo.com/en-gb/News/2023/October/Ask-the-Developer-Vol-11-Super-Mario-Bros-Wonder-Chapter-1-2460393.html)：試作で驚きと遊びの核を探る | 部屋数を増やす前に、短い体験で独自性を確かめる |
| 佐藤ら / 任天堂 | [同インタビュー第2章](https://www.nintendo.com/en-ca/whatsnew/ask-the-developer-vol-11-super-mario-bros-wonder-part-2/)：遊ぶカメラから表情や動きが伝わるよう調整する | 正解時に引き出しを文章で隠さず、鍵が見える角度へ寄る |
| Scott Nicholson | [2016年「Ask Why」](https://scottnicholson.com/pubs/askwhy.pdf)：脱出ゲームの課題を世界観と目的に一貫させる | 和室にある理由が伝わる錠と手がかりにする。実空間の脱出ゲーム研究からの応用 |

大ヒットは約束できない。目指すのは、人が自分で発見し、誰かに話したくなる具体的な瞬間をつくり、観察結果から磨くこと。
