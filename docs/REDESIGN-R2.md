# 余白 再設計R2 — 分かって試せて、景色が応える

2026-10-22。ユーザーの「操作も謎も進行も分からない」「一般的な脱出ゲームの操作を調べる」「謎は大きく変更してよい」を受けた次期版の仕様。**公開v1.5.0で、スライド見回しと画面下の移動矢印を先行実装。近接から戻る・詳細の拡張と、五問は未実装。** 制作順は[ロードマップ](ROADMAP.md)、確認方法は[試遊計画](PLAYTEST.md)を参照。

## 原因と判断

| 現行版の問題 | プレイヤーが判断できないこと | 次期版で変えること |
|---|---|---|
| スワイプが歩行・旋回・神目線の回転を兼ねる | 触った後にどう動くか予測しづらい | 調査・移動はタップ、ドラッグは見回しへ整理 |
| カメラの正解位置で「写す」が出る | 模様を理解したのか、位置判定を踏んだだけなのか | 図は常に読める。記録は解釈前の見た目を残し、答えを代わりに出さない |
| 三・一・五を松竹梅と格子へ割り当てる | なぜその墨がその草木で、なぜ行と列なのか | 同じ形・枠・場所を比較して、対応の根拠を確かめられるようにする |
| 格子と箪笥へ同じ数字を入れる | 二度使う意味や、世界で起きた変化 | 現行315と格子の二重入力を外し、道具・建具・紋札に違う役割を与える |
| 物を別の部屋へ移しただけ | なぜ今そこへ行くのか | 使いたい物を先に見せ、その用途を後から理解できる発見を分散 |
| テスト24件と作者の通し操作を品質の説明に寄せた | 初見の人が推理できるか、面白いか | 機能確認と、人による理解・楽しさの判定を分ける |

難しさ以前に、次の行動を選ぶ証拠が足りない。散布の目的は距離を増やすことではなく、先に見た物の意味が後からつながること。

## ゴールと世界の約束

目的は館の玄関の鍵を見つけて外へ出ること。玄関の鍵穴と、近くにある「三つの紋札をはめる木箱」を先に見せる。木箱には鍵の意匠を付け、札を探す目的を示す。

見立てや隠し建具を好む木工職人の館、という最小限の設定にする。長文で解法は語らない。継ぎ目・取手の穴・薄い紙・引き戸の重なりなど、物の性質を考える材料にする。3D空間、自由な360度の見回し、神目線と室内視点は残す。制限時間は入れない。

先に主要な謎5問＋探索・道具使用を一続きにする。10〜15分は未検証の仮目標。30問は拡張候補として残し、拾う・移動するだけの操作を謎の数に水増ししない。電池残量やOS通知など、端末外部の状態を解法に使わない。

## 操作の調査と採用

Jammsworksの開発者掲載の説明ではタップ調査・移動矢印・アイテムのダブルタップ拡大・選択して使用が案内されている。FUNKYLANDもタップ中心の操作・アイテム拡大・自動保存を案内している。この二例の共通部分を基礎にする。全作品に一つの規格があるとは扱わない。

| 操作 | 次期版の動作 | 守ること |
|---|---|---|
| 対象をタップ | 寄って正面から調べる。近接中なら動かす・拾う | 調査のつもりで意図しない歩行が始まらない |
| 画面下の移動矢印 | 今向いている方向の、到達可能な場所へ移動する | 行けない方向・到着済みの場所は表示しない。v1.5.0で先行実装 |
| ドラッグ | 室内では見回し、神目線では部屋を回す | ドラッグ後のタップ誤発火を防ぐ |
| 出入口をタップ | 隣の区画へ進む | 画面下の移動矢印からも選べる |
| 近接時の下矢印 | 一つ前の視点へ戻る | 全景への初期化と混ぜない |
| アイテムを1回タップ | 使用する物を選ぶ | 選択を見た目で示す |
| 同じ物を間を置いて再タップ | 選択解除 | 既存のユーザー指定を残す |
| 素早く2回タップ | 詳細を開き、裏返し・回転・拡大 | 直後の解除を誤発火させない。目の印も詳細を開く代替操作 |
| 選択して対象をタップ | 道具を使用 | 所持だけで自動使用しない。間違っても物を失わない |
| 上部の〈 〉 | 持ちものを収納・展開 | 選択中の小さな図は残す |
| 足跡／俯瞰アイコン | 室内と神目線を切り替える | 室内視点で開始。神目線を覚える前に最初の一問を解ける |
| ヒントボタン | 観察先→関係→具体操作の順に任意表示 | ヒントを見るだけで進行しない |

全ての必須操作にタップの代替を置く。3D空間の移動は画面下の行き先矢印と対象のタップ接近で維持し、スライドは見回しだけにする。数字錠を将来使う場合は上下式を残すが、今回の五問には使わない。

## 各問の設計

### P1：屏風と小箱 — 最初の納得

**目的・場所**：静寂の間。取手のない引き出しがあり、隣の小箱に取手が見えている。

**見える証拠**：屏風の三面に松・梅・竹の紋。小箱の三つの窓でも同じ紋を選べる。同じ三分割の枠、同じ隅の赤い印がある。

**推理と操作**：「同じ枠だから、屏風の配置を小箱へ写す」。窓をタップし、左から松・梅・竹へ合わせる。これは新案の値であり、現行315とは無関係。

**なぜそうなるか**：枠・向き・隅印の一致から、三か所を直接比較できる。読む順の暗黙の文化知識を要求しない。比較画面は同じ正面から見る。

**結果**：留め金が外れ、取手を取れる。取手の二本の足と引き出しの穴が同形。選んで使うと引き出しが開き、透かし紙と館の見取り図を得る。

**楽しさの狙い**：最初の一問で「気づいたら開いた」を経験する。選択→使用と詳細表示を短い距離で覚える。取手を使う操作は別の暗号問題として数えない。

**誤答とヒント**：紋は自由に戻せ、間違えても物を失わない。ヒントは「同じ三つの枠」→「隅の印で向きをそろえる」→「松・梅・竹」。

### P2：灯りに透かす見取り図 — 紙は読むだけではない

**目的・場所**：静寂の間で得た紙を、表廊下の行灯に使い、竹の紋札を見つける。

**見える証拠**：紙には薄い廊下の線と灯りの印。四隅の切り欠きが行灯の紙留めと同じ形。廊下には竹を彫った柱が一本あり、紙にも同じ柱が描かれている。

**推理と操作**：「薄い紙を、この枠の灯りに透かせる」。紙を選んで行灯へ使う。透けた図では竹の柱の根元だけに印が現れる。

**なぜその場所か**：廊下の形、竹の柱、印の位置の三つが一致し、場所を一か所へ絞れる。植物名を数字へ変換しない。

**結果**：柱の根元を調べると床板の縁の隙間が見える。タップで押して開き、竹の紋札を得る。

**楽しさの狙い**：道具の使い方を思いついた後、実物の場所を見つける。移動に自分で決めた目的が生まれる。

**誤答とヒント**：違う物には紙がはまらない。正しい枠には収まる予告を見せる。ヒントは「紙の薄い線・切り欠き」→「同じ枠の行灯」→「図の柱の根元」。

**先回り**：床板を先に見つけても成功。「先に紙を見た」というフラグで拒まない。灯りは透過画像の合成で表現でき、リアルタイムの影を必須にしない。

### P3：上から見る木工模型 — 神目線に理由を与える

**目的・場所**：書院。三枚の回転板を持つ見立て箱から松の紋札を取る。

**見える証拠**：線は板の上面だけにあり、側面からはつながりが読めない。箱の縁には完成した松の枝の図。図と模型に同じ隅の切り欠き。回転軸と三つの固定具も見える。

**推理と操作**：「上面を、見本と同じ向きからつなぐ」。俯瞰へ切り替え、板をタップして90度ずつ回す。カメラは読みやすい位置へ寄るが、板を自動で正解にはしない。

**なぜ一意か**：枝と外周の線が三枚全てをまたぎ、他の向きではどこかが切れる絵にする。実装前に全64通りで一致が一つかを検証する。

**結果**：線がそろうと固定具が外れ、箱が開いて松の紋札が現れる。

**楽しさの狙い**：神目線を「カメラ操作」から、情報を理解する道具へ変える。特定位置で出る「写す」を探す操作にはしない。

**誤答とヒント**：切れた線が見え、自由に回して戻せる。ヒントは「模型の上面と見本」→「隅をそろえて上から」→「三枚の境目と外周を全部つなぐ」。

**先回り**：どの順で回しても、形が合えば開く。神目線に切り替えた履歴そのものを正解条件にしない。

### P4：閉じられない知らせ — 予想を変える一問

**発生・場所**：松と竹を得て静寂の間へ戻ると、正面の神目線に一度だけ和紙の知らせが出る。梅を先に得ていれば出さない。

**見える証拠**：前面の閉じる印に触れても消えず、紙が少し傾く。厚み、端へ回り込む墨、床への影で、普通のUIと違う兆候を見せる。

**推理と操作**：「これも部屋の物なら、裏がある」。神目線で回すか、室内から回り込んで裏を見る。

**裏の情報**：同じ鶴の引き戸が開いた絵と閉じた絵。閉じると二つの翼が一羽になり、くちばしが左の壁際を示す。枠・隅印も実物と一致する。

**次の推理**：「開けるのでなく閉じて、絵をつなぐ」。二枚を閉めると鶴が完成し、重なっていた戸が動くため左の収納が実際に露出する。

**結果**：梅の紋札を取れる。鶴がつながり収納が見えた時点で知らせは畳まれて退く。裏の図は覚え書きに残る。

**楽しさの狙い**：裏返して調べるという既知の操作を、UIだと思った物へ応用する。奇妙さには兆候を置き、根拠なしに操作を裏切らない。

**誤答とヒント**：本物の戻る・ヒント・設定は常に動く。紙は部屋に固定し、別室まで視界を塞ぎ続けない。ヒントは「紙の端・厚み」→「部屋の物として裏へ」→「同じ鶴の戸を閉める」。

**先回り**：先に戸を閉めても梅を取れる。裏面の読了フラグは要求しない。プレイヤーの合理的な先取りを成功として受け入れる。通常操作を信頼してから置く。

### P5：紋札の裏が館になる — 探索の意味を回収

**目的・場所**：玄関前の木箱から、出口の鍵を得る。

**見える証拠**：木箱の三つの欠けた枠と鍵の意匠。札の表は松竹梅、裏には部屋の輪郭と廊下の線。序盤の見取り図と同じ柱・玄関が描かれている。

**推理と操作**：「草木の順に数字を入れるのでなく、裏をつなぐと歩いてきた館になる」。詳細で裏を見て、一枚ずつ箱へはめ、回して壁と通路をつなぐ。

**なぜ一意か**：外形、壁の続き、玄関の位置の三条件で配置を一つにする。作者が決めた植物の順を当てさせない。

**結果**：館の図が完成すると側面が開き、鍵が出る。鍵を選んで玄関の鍵穴へ使い、戸を開けて脱出する。

**楽しさの狙い**：集めた物と、自分が歩いた空間が最後に一つの意味になる。最後の鍵使用はP1で覚えた道具使用の回収で、もう一問とは数えない。

**誤答とヒント**：札は自由に外せる。壁の切れ目は見えるが自動補完はしない。ヒントは「札の表以外」→「見取り図と同じ柱・玄関」→「外形と通路が続く向き」。

## 順路と情報の負荷

P1と取手使用で紙・見取り図を得る。P2とP3は順不同。両方の札を得て帰るとP4の知らせ。三枚でP5へ進む。P4を先に解く順序も許す。

導入は一度に一つの新しいルール。中盤に抱える未解決の問いは原則二つ。使いたい対象を先に見せ、別室の情報で用途が分かる配置にする。現在地と訪問済みを地図に残すが、未解釈の図を勝手に解読しない。

## 実装前の約束

各問で目的・証拠・仮説・操作・結果・先回り・誤答・ヒントを埋める。欠けた問題は配置しない。紋や図形や札の形はまだ制作前。コード上の正解が一つでも、別の解釈が人間に成立する絵なら作り直す。人が楽しんだという結果は、本書を作っただけでは確認できない。
