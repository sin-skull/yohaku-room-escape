# ゴールとロードマップ

見た目を増やす量ではなく、人が遊べた証拠で次へ進む。以下の数値は今回設定する目標であり、達成済みの実績や業界平均ではない。日数は担当人数・稼働が未確定のため作業日での概算。

## 最初の到達点

「和室の景色を読むことが謎解きになる」一部屋を完成させ、初見の10人が作者の口頭説明なしで遊べる状態を確かめる。

| 評価 | 次段階へ進む目安 |
|---|---|
| 操作導入 | 10人中8人が20秒以内に最初の物を調べる |
| 納得 | 10人中8人が手がかりと解答の関係を自分の言葉で説明できる |
| 発見 | 10人中7人が、助言前の自発的な発見を2回以上経験する |
| 継続意向 | 10人中6人以上が次の部屋を遊びたいと答え、理由を聞ける |
| 完成版の尺 | 30段階案では中央値30〜45分を仮目標とする。現在の短い試作には適用しない。密度に応じて段階を削る |

10人は改善点を発見するための規模。市場全体の人気や拡散率を推定する根拠にはしない。

## 制作順

| 段階 | 作業日目安 | 制作内容 | 完了の条件 |
|---|---:|---|---|
| M0 方針と基礎 | 今回 | ES図、技術監査、和紙UI、拡大縮小、数字錠 | 通しプレイと公開確認。実装済み項目を技術監査に記録 |
| M1 操作の安定 | 2〜3 | 実機でピンチ・上下操作・保存復帰・誤タップを修正 | iOS Safari / Android Chromeの実機で進行不能ゼロ |
| M2 遊びの核 | 3〜5 | 障子・光・余白の90秒グレーボックス試作を別入口に用意 | 説明せずに意図した発見が起きる。起きなければ作り直す |
| M2b 分岐の確認 | 4〜7 | 松・竹・梅の答えを分散。三枝→箪笥と、その前提の一枝を実装 | 情報を探すだけでなく、関係を推理できる。30段階案への拡張を判定 |
| M3 一部屋の完成見本 | 5〜8 | 探索→推理→空間の変化を2〜3段階にする。美術・効果音を統合 | 全ての装飾に役割があり、ヒントなしでも因果が伝わる |
| M4 人による試遊 | 3〜5 | 初見10人の観察、問題の分類、改修と再試遊 | 上の目安を確認。未達なら部屋数を増やさない |
| M5 公開ベータ | 5〜7 | 50人規模の任意試遊、端末差の修正、ネタバレしない結果共有 | 致命的不具合ゼロ。共有導線の使用と実際の流入を区別して評価 |
| M6 正式公開 | 状況で決定 | タイトル画・紹介動画・公開文・初動改善 | 遊べるURL、権利表記、復帰手順、問い合わせ導線が揃う |

「バズ」は制作完了条件に置かない。共有したくなる場面を仮説にし、任意の感想や紹介を観察する。本人が操作するまでSNSに投稿しない。個人情報や行動解析の自動送信は現行版に追加しない。
