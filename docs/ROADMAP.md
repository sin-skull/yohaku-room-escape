# 制作ロードマップR2 — 操作と推理を組み直す

2026-10-22改訂。公開ゲームはv1.5.0。スライド見回しと到達可能な移動先の矢印を先行実装した。移動・保存の機能は動くが、ユーザーから操作・謎・進行の全てが分かりにくいとの指摘を受けた。**「区画の完成見本」は機能試作へ判定を戻す。** 自動テスト24件は、初見の理解や楽しさの合格を意味しない。

今回の成果は[再設計R2](REDESIGN-R2.md)。移動操作は先行実装済み。近接から戻る・詳細の拡張・新しい五問は未実装。[拡大できる進行図と各問の根拠](../project.html)も参照。

## 到達点

「気になる→証拠を見つける→使い方を考える→試す→景色が応える」を三つの区画で成立させる。先に主要な謎5問＋探索・道具使用で、館からの短い脱出を完成させる。10〜15分は未検証の仮目標。

30問案は拡張候補として保存する。先に数を埋めず、一連が遊べた後、新しい発見を説明できる問題だけ増やす。次の魔法脱出へ早く進むため、短い完成版を終える基準を置く。

## 実装順と合格条件

| 段階 | 状態 | 作るもの | この順番の理由 | 次へ進む条件 |
|---|---|---|---|---|
| R0 原因と再設計 | 今回作成 | 既存版の診断、公式操作の調査、五問の証拠・操作・結果・別解と進行図 | 分からない構造のまま部屋を増やさないため | 各問に、答えを知らない人が仮説を立てる根拠を明記。人による設計確認は未実施 |
| R1 操作 | 一部実装・v1.5.0 | スライド見回し・行ける場所だけ表示する画面下の移動矢印は実装済み。近接から戻る、詳細と裏返しは未実装 | 操作の迷いと推理の難しさを分けるため | 謎なしの操作見本で、調査・戻る・選択・使用・解除を口頭補助なしで行える。実機で誤発火を確認 |
| R2 導入一問 | 未実装 | 屏風と小箱、取手、透かし紙の取得 | 最初の成功と、後で使う操作を短く学ぶため | 初見3人中2人が、ヒントなしで対応の理由を説明できることを暫定目安にする。未達ならここを直す |
| R3 中盤二枝 | 未実装 | 透かし紙と廊下、模型と俯瞰 | 道具と視点の発見を別々に学ぶため | 順不同で進め、なぜ行灯・柱・上面を見るかを説明できる。回転図形を全候補で検証 |
| R4 予想の転換 | 未実装 | 立体の知らせ、その裏、閉めてつながる鶴の戸 | 通常操作を信頼してから役割を読み替えるため | 紙の実在の兆候が見え、バグ扱いで放置されない。先に閉める別順も成功 |
| R5 最後の集約 | 未実装 | 札の裏と館の図、鍵、玄関 | 集めた物と歩いた場所の意味を回収するため | 通し脱出、別順、誤答、途中保存、再開が成立。札の消失や詰みがない |
| R6 人が遊べる状態へ | 未実施 | 初見の通し試遊、読みやすさと往復の修正、動き・音、実機評価 | 作者の答えを知った操作だけでは判断できないため | 下の完成条件を確認。未達なら原因の段階へ戻し、問題数は増やさない |
| R7 和室版を一段落 | 未到達 | 公開URL、既知の不具合、再開手順、短い紹介 | 次の作品へ移る境界を明確にするため | 試遊結果と制約を記録して公開。移動・入力・保存を魔法脱出へ引き継ぐ |

日数は担当・稼働・試遊確保が未定のため確約しない。**次の実装単位はR1の残り→R2。五問をまとめて実装する前に、操作と最初の納得を検証する。**

## 暫定の完成条件

数値は今回置く判定目安。業界標準や達成済みの実績ではない。少人数から市場の人気を推定しない。

| 見ること | 暫定目安 | 未達時の修正 |
|---|---|---|
| 操作 | 最終の初見5人中4人が、口頭補助なしで調査・戻る・使用できる | 入力と表示を直し、謎のヒントで覆い隠さない |
| 納得 | 各主要問で5人中4人が、証拠と操作のつながりを終了後に説明できる | 形・枠・場所・変化の対応を直す |
| 発見 | 5人中3人以上が、自分で思いついて試した場面と根拠を具体的に挙げる | 兆候と試す余地を見直す。派手さだけで合格にしない |
| ヒント | 使った人が次の試行を説明できる。第一段階で答えを渡していない | 観察先→関係→操作に分ける |
| 進行 | 誤答・再開・先回りを含め進行不能ゼロ | 状態管理を自動検証。理解の評価と混ぜない |
| 実機 | iOS SafariとAndroid Chromeで全必須操作、中断復帰、回転を確認 | 模擬390px表示だけで合格にしない |
| 性能 | 共通画像、DPR上限1.5、区画単位描画を維持し、実機で遅延を確認 | 視認性に不要な立体細部と再描画を減らす |

「面白かった」だけでなく、どこで何を見てどう考えたかを残す。苦痛なつまずきを平均点で埋めない。

## 残す・置き換える・後に回す

- 残す：3D、自由な見回し、神目線と室内、区画移動、軽い当たり判定、上部の収納式持ちもの、選んで使用、保存、和紙・墨・木。
- 置き換える：長押しスワイプ前提の歩行、正解位置限定の写す、315と格子の二重入力、用途の分からない運搬。
- 後へ回す：30問と大きな館、秒数制限、端末外の状態を使うメタ操作。時間制限は今回も入れない。

R1で入力の優先順位と「戻る」を確定。R2で同じ枠と隅印の絵、形の合う取手と穴を制作する。初見の合格を設計書だけで完了扱いにしない。
