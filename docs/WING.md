一部屋に詰め込んでいた手がかりと仕掛けを「静寂の間・表廊下・書院」へ分ける。発見した場所と使う場所を離し、移動によって情報の意味がつながる構成に変更した。

| 場所 | 置くもの | 役割 |
|---|---|---|
| 静寂の間 | 掛け軸、松竹の格子、花紋 | 関係を知り、別の場所で得た情報を集約する |
| 表廊下 | 覗き棚、二つの部屋への襖、玄関 | 歩行視点の発見、移動と帰還、最終の鍵の使用 |
| 書院 | 高い飾り棚、文机、箪笥 | 神目線の発見、覚え書きの確認、数字錠と鍵の取得 |

## 遊べる順路（解答を含む）

静寂の間の掛け軸 → 廊下の覗き棚で竹の「一」 → 書院の棚を俯瞰して松の「三」 → 静寂の間へ戻り、格子の三段目・一列目 → 梅の五弁を写す → 書院の箪笥へ315 → 鍵を取る → 廊下で鍵を選び、玄関の襖へ使う。

松と竹は順不同。調査対象と解答は覚え書きに持ち帰れる。移動先を示す短い墨書きと、現在地・訪問済みの印を載せた「間取」で方向を確かめる。ヒントボタンには場所も含めた段階ヒントを用意する。

## 操作と保存

神目線でも歩行視点でも、襖の目印をタップして行き来できる。歩行中は敷居まで歩くことでも移動する。移動すると動きを止め、次の場所の室内に入る。アイテムの選択中でも部屋間の移動はできる。

場所、訪問済みの区画、観察、仕掛け、数字、持ちものを保存する。中断・再読み込み時には現在地と視点を復元する。旧版で得た情報や鍵は失わない。旧版の「脱出済み」は過去の試作の達成として維持し、新規の通しプレイは設定の「はじめから」で開始できる。

現在地の3D区画だけを描画し、移動時に前の描画資源を解放する。木目・畳・和紙は既存の共有画像を使う。制限時間と物理演算は追加しない。

## 今回の到達点と次の制作

今回の到達点は、三か所を巡る短い脱出の完成見本。新しい謎を大量追加するより、発見・往復・集約・鍵の使用が迷わずつながることを優先する。約30段階、松竹梅それぞれの主要部屋、大広間、通知の裏へ回る仕掛けは未実装の拡張候補。

初見試遊で移動先の認識、手がかりの記憶、往復の負担を確認し、進行不能や読みづらさを直して一段落とする。その後の魔法脱出ゲームには、視点切り替え・入力・持ちもの・保存・区画移動を再利用する。魔法作品自体はこの更新では開始しない。
